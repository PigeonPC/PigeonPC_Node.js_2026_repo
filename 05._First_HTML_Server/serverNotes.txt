PUBLIC MAPPEN

alt i public mappene er PUBLIC!
Når man server public mappen som static, kan de serves public.

Når man tilføjer denne linje til app.js:

    app.use(express.static('public'));

Giver den adgang til CSS filen!! Dvs den er public!!
Den gør public mappen static!
Vi opdeler public mappen i flere undermapper, for overskueligheds skyld.

Det er en sikkerhedsfeature, at man fx ikke kan skrive 
Localhost:8080/.env
Eller lign, så man bare kunne skrive en mappestruktur URL.
Derfor findes en public mappe, der styrer hvilke filer, der er public!

CIRCULAR DEPENDENCY PROBLEM

Hvad gør man hvis man har tre filer, der alle er afhængige af hinanden i en trekant.

    <script type="module" src="/fruits/fruits.js"></script>
Man kan definere en fil som Modul!
Det betyder at man kan bruge den som en form for master, der kan importere de andre filer.

I fruits.js har vi tilføjet
    import fruitProcessingPlant from './fruitsOrchard.js'

Og i fruitsOrchard.js tilføjet *DEFAULT FUNCTION!*
        export default function fruitProcessingPlant()  {
        return ["orange", "apple", "cherry", "bird"]
    };
